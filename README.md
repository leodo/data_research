# 投研指标工作台

基于公开数据自算的本地指标站点：恐贪指数（7 个指数）与市场情绪面板。纯静态页面 + Python 数据脚本，无后端、无数据库、无第三方付费接口。

| 页面 | 地址 | 内容 |
|---|---|---|
| 首页 | `http://localhost:8040/index.html` | 导航与概览 |
| 恐贪指数 | `http://localhost:8040/indicators.html` | 7 指数恐贪值、区间切换、因子拆解 |
| 情绪面板 | `http://localhost:8040/mood.html` | 8 项综合情绪指标 + 交易拥挤度 + 4 张结构观察卡片 |

情绪面板的 4 张结构观察卡片（均**不计入综合情绪分**）：头部 300ETF 占比、两融余额 60 日增速、全 A 站上 200 日均线占比、全 A 市净率中位数（月频）。

## 快速开始

```bat
启动.bat
```

或命令行：

```bash
python -m pip install -r requirements.txt
python start_site.py            # 按需更新数据并启动，自动打开浏览器
python start_site.py --force    # 强制重建全部数据后再启动
python serve.py                 # 只起静态服务，不更新数据（调试页面时用）
```

按 `Ctrl+C` 或关闭窗口停止服务。端口固定 `8040`（`config.py` 中定义），若被占用会提示已有实例在运行。

依赖环境：Python 3.13 + akshare 1.20.65（见 `requirements.txt`）。ECharts 5.6.1 已放在 `vendor/`，页面完全离线可用。

## 代码结构

```
编排层   启动.bat → start_site.py          新鲜度判定 + 显式 DAG 编排 + 静态服务
计算层   build_fear_greed.py              7 指数恐贪（独立链）
         rebuild_turnover.py             全市场换手率（交易所口径）      ┐
         build_crowding.py               交易拥挤度                      │
         build_etf_ratio.py              头部 300ETF 占比                │ 情绪链上游
         build_margin.py                 两融余额增速                    │
         build_pb.py                     全A PB（月频）                  │
         build_breadth.py                全A 市场宽度（收盘价缓存）      ┘
         build_mood.py                   情绪面板汇总 + 输出
公共层   config.py                        全局口径系数、抓取参数、端口
         core.py                          路径/日期/日志/缓存/分位/交易日历
         app.js                           前端公共层：十字准星 helper + 二级目录组件 mountToc()
         app.css                          三页共用主题变量（浅/暗双主题）+ 目录样式
数据层   data/                            CSV 缓存 + JSON/JS 输出（派生产物，不入库）
展示层   index.html / indicators.html / mood.html / vendor/
archive/                                治理前旧版脚本快照（可回溯）
```

`build_mood.py` 内部按「取数 `load_sources()` → 指标注册表 `METRIC_BUILDERS` / `MACRO_BUILDERS` → 组装 `build_composite()` → 输出 `write_output()`」四层组织，每个指标一个 `calc_*` 函数。**新增指标只需写一个 `calc_*` 并在注册表登记一行**，不用动 `main()`。

`start_site.py` 的 `PIPELINES` 定义了显式依赖顺序，情绪链必须按
`rebuild_turnover → build_crowding → build_etf_ratio → build_margin → build_pb → build_breadth → build_mood`
执行，否则汇总脚本读到的是旧的上游数据。新增构建脚本时要同步登记到这里。

## 页面内二级目录

`mood.html`（17 个锚点）与 `indicators.html`（4 个锚点）在页面顶部有吸顶目录条，侧边栏同步生成二级树。一级目录是页面分组，二级是该组卡片。**默认全部展开**：目录条一次列出所有卡片（按分组标签分隔），侧栏所有分组也默认展开；点某分组 = 只看该组，点「全部展开」恢复。

- 点击卡片平滑滚动定位，卡片边框闪烁提示，地址栏 hash 同步更新，**链接可直接分享到某张卡片**（如 `mood.html#toc_pcr`）。
- 只有 1 张卡片的分组（如"交易拥挤度"）点一下直接跳转。
- 按 `/` 聚焦搜索框，输入名称即时过滤，`↑` `↓` 选择、`Enter` 跳转、`Esc` 关闭。
- 页面滚动时自动高亮当前卡片，但**不会**把「全部展开」视图收成单组；"收起"状态按页面记忆在 `localStorage`。

目录由 `app.js` 的 `mountToc()` 扫描 DOM 自动生成：**卡片只要加 `data-toc="名称" data-toc-group="分组"` 就会自动进目录**，新增指标不需要改目录代码。页面在 `render()` 完成后调用一次 `mountToc({app:"#app", bar:"#tocBar", side:"#tocSide"})` 即可。首页只有 2 张入口卡、一屏可见，未启用目录。

## 数据更新策略

数据源发布时间不一致是常态（盘后当日并非所有源都出数），因此按三类区别处理，不做"一刀切"增量：

- **A 类 · 真增量**：PCR 用按日接口，读缓存末日、回溯 3 天重叠、只补后续交易日（`build_mood.py --pcr-full` 可全量重建）。
- **B 类 · 整抓即最新**：申万行业、基金指数、两融账户统计、全 A PB 等接口一次返回全历史，重抓就自动吸收新数据，无需增量。申万额外做了 31 个行业独立 CSV 缓存 + 拒绝数据倒退保护。
- **C 类 · 昂贵/不稳定**：成分股强度需全量重抓（约 771 秒），按官方交易日历容忍 3 个交易日滞后，用 `*_stamp.txt` 保证同一自然日最多刷一次，失败降级沿用旧缓存。拥挤度与市场宽度按个股独立 CSV 断点续抓，已有缓存只补最近几个交易日。

启动器的新鲜度判定不看"数据日期是否等于今天"（那样会因个别源永远滞后而每次启动都重建），而是用 `data/last_update.json` 记录**今日是否已尝试更新**；同一天重复启动直接跳过，需要重跑用 `--force`。页面各卡片会显示真实截止日与滞后天数，请以卡片为准，不要只看全局日期。

`data/` 是派生产物，不纳入版本控制。克隆仓库后首次运行会重新抓取，其中全 A 个股成交额、全 A 个股收盘价各需约 20 分钟（各 5579 只）、成分股强度约 13 分钟、ETF 份额约 8 分钟，均为断点续抓，中断后重跑可继续。

## 口径与已知局限

- **全市场换手率**是分段近似：深交所数据 2021-07 后接口返回坏档，改用 2015–2021 深市×`0.72`、2022 起沪市×`1.36` 换算到全市场量级，绝对值有约 10–20% 误差，分位走势可靠。图中同时叠加了上交所官方口径与"历史水位（分位）"线，用于跨时代比较。2024-09 后的换手率台阶是"924 行情"真实放量，非拼接错误。
- **PCR 方向**：A 股持仓 PCR 是顺周期指标（与沪深300 价格正相关约 +0.45），低 PCR 对应市场底部、是布局机会，与美股教科书结论相反，已用本地 1422 日样本验证。
- **A 股风险溢价 rp**：`stock_market_pe_lg` 的 `symbol` 参数已失效，当前实际用的是科创板 PE，该值失真，暂未替换数据源。
- **交易拥挤度 / 市场宽度**：股票池为当前在市 A 股，存在幸存者偏差；收盘价为未复权口径，除权跳空对横截面统计影响有限；市场宽度要求个股上市满 200 个交易日才纳入。
- **全 A PB** 为月频（约 263 个月点），与日频指标不同频，区间切换按数据点计；卡片已标注"月频"。
- **申万行业**、**50ETF QVIX**、**两融账户统计**等源可能滞后数日；`allmarket` 恐贪常因此停在前一交易日。这属于数据源节奏差异，不是脚本故障。
- 口径系数（换手率桥接、市值锚、均线窗口、抓取参数等）集中在 `config.py`，注释里写明了实测依据。中证1000 QVIX 回归系数是运行时拟合的，不是固定常量。

## 常见问题

- **一直显示"数据加载中"**：确认是通过 `http://localhost:8040/...` 访问而非直接双击 HTML（`file://` 下 fetch 会被拦截）。
- **数据日期不齐**：正常现象，卡片上的"数据至 YYYY-MM-DD"才是真实截止日。
- **想强制刷新**：`python start_site.py --force`，会透传给所有构建脚本。
- **改错了想回滚**：`git log` / `git diff` 可用；`archive/` 保存了治理前的旧版脚本快照。
- **改配色**：只改 `app.css` 的 `:root` / `[data-theme="dark"]` 即可，三页共用。
- **新增卡片没进目录**：确认元素上有 `data-toc` / `data-toc-group`，且 `mountToc()` 在 `innerHTML` 赋值之后调用。
- **目录挡住卡片标题**：目录条吸顶偏移是动态计算的；若调整了 `.topbar` 高度，检查 `app.js` 的 `offset()`。
